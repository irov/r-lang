# Radix and integer representation calculator

Convert numbers between representations and compare checked, wrapping, and saturating
arithmetic. This is a command-line tool: each operation consumes arguments and prints its result.
A checked overflow prints `overflow`; invalid input produces a diagnostic and exits with 65.

Build and run from the repository root:

```sh
cmake -S . -B build-debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build-debug -j8
ctest --test-dir build-debug -R '^r_frontend_codegen_example_numbers$' --output-on-failure
build-debug/tests/codegen_example_numbers parse u32 ff 16
build-debug/tests/codegen_example_numbers parse u32 0xff 0
build-debug/tests/codegen_example_numbers checked_add u8 255 1
build-debug/tests/codegen_example_numbers wrapping_add u8 255 1
build-debug/tests/codegen_example_numbers saturating_add u8 255 1
build-debug/tests/codegen_example_numbers limits i16
build-debug/tests/codegen_example_numbers convert c_long_double 1.25
build-debug/tests/codegen_example_numbers count_ones i8 -1
build-debug/tests/codegen_example_numbers rotate_left u8 129 1
build-debug/tests/codegen_example_numbers widening_mul u64 18446744073709551615 2
build-debug/tests/codegen_example_numbers narrowing_div u32 1 0 3
```

These commands print `ff`, `255`, `overflow`, `0`, `255`, `-32768 32767`, `1.25`, `8`, `3`,
`18446744073709551614 1` and `1431655765 1`.
Run without arguments for syntax. `parse` accepts an optional input/output radix; radix zero
recognizes a prefix and prints decimal. Floating-point input/output is decimal.
`convert` uses checked numeric conversion from an `f64` input; `c_convert` selects the C bridge.
`limits` and the nine arithmetic commands apply to the ten R integer types, and so do the bit
commands `leading_zeros`, `trailing_zeros`, `count_ones`, `swap_bytes`, `rotate_left` and
`rotate_right` (the last two take the rotation count). The wide commands apply to the unsigned
types: `widening_mul` prints the low and high halves of the product, `carrying_add` and
`borrowing_sub` take a third value, 0 or 1, as the incoming carry or borrow and print the result
and the outgoing one, and `narrowing_div HIGH LOW DIVISOR` divides the double-width value and
prints the quotient and remainder, or `overflow` when HIGH is not below DIVISOR.

Typed modules make every public specialization visible in working code, including C aliases.
They are generated by `tools/generate_numeric_example.py`; edit that generator when changing
the dispatch, and run it from the repository root. The CLI and its error handling are handwritten.
`tests/run_numeric_examples.py` checks results independently, including every R integer's
minimum, maximum, overflow, saturation and wrapping behavior.
